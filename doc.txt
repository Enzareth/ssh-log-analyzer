### 🕵️ SSH Log Analyzer

Le projet consiste à créer **un programme Python qui prend les logs SSH d'un serveur Linux et les analyse automatiquement pour repérer les activités suspectes**.

Concrètement, tu as un fichier comme :

```text
auth.log
```

qui contient des événements SSH :

```text
Failed password for root from 192.168.1.50
Failed password for admin from 192.168.1.50
Accepted password for sofian from 192.168.1.20
Invalid user test from 192.168.1.50
```

Ton **SSH Log Analyzer** va lire ces lignes et en extraire les informations importantes :

```text
Date / heure
    ↓
Type d'événement
    ↓
Utilisateur
    ↓
Adresse IP
```

Puis il va les analyser.

### Exemple

Ton programme trouve :

```text
192.168.1.50 → 1 tentative
192.168.1.50 → 1 tentative
192.168.1.50 → 1 tentative
...
192.168.1.50 → 45 tentatives
```

Il peut alors conclure :

```text
🚨 ALERTE

IP : 192.168.1.50
Tentatives échouées : 45
Type : Brute-force SSH potentiel
Gravité : HIGH
```

### Donc ton projet suit ce principe

```text
Serveur Linux
     │
     ▼
auth.log
     │
     ▼
SSH Log Analyzer
     │
     ├── Analyse des connexions
     ├── Analyse des IP
     ├── Analyse des utilisateurs
     ├── Comptage des échecs
     └── Détection d'activités suspectes
             │
             ▼
          Rapport
```

### 🎯 Le vrai objectif

> **Développer un outil Python capable d'analyser automatiquement les journaux SSH afin d'identifier les tentatives de connexion suspectes et de détecter notamment les attaques par brute-force.**

Et tu peux le faire **entièrement en Python au début**.

Ensuite, si tu veux approfondir, tu ajoutes :

1. **Analyse des logs**
2. **Détection de brute-force**
3. **Statistiques sur les IP/utilisateurs**
4. **Base SQLite**
5. **Dashboard Web**
6. **Alertes**
7. **Analyse de plusieurs serveurs**
8. **Détection d'anomalies avec IA**

Donc le **SSH Log Analyzer est le projet de départ**. Tu n'es pas obligé d'en faire un SIEM complet.
